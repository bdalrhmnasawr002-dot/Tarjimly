# Tarjimly
تطبيق ترجم لي (Tarjimly) هو تطبيق أندرويد لترجمة ملفات PDF من اللغة الإنجليزية إلى اللغة العربية. يستخرج النصوص من الصفحات المكتوبة والمصوّرة باستخدام تقنية OCR، ثم يترجمها ويُنشئ ملف PDF جديدًا، بحيث يظهر كل نص إنجليزي وتحته ترجمته العربية بخط واضح وكبير، مع واجهة عربية بسيطة وسهلة الاستخدام.
